Align: Neo-brutalism and Minimalism

Two complete directions, each on the real Align content: the six live briefs, Rohan's pitches and the admin pitch queue. Each direction shows five phone screens (briefs, brief page, dashboard, pitch form, log in) and the desktop admin queue. Everything is clickable: filters, likes, pitch formats, and Shortlist / Approve / Not selected in the admin queue (keys S, A, N).

Fonts were picked for Align, not from the usual lists. Most come from Indian Type Foundry's free Fontshare library (free for commercial use). The Devanagari partners are there because Hindi screens are planned. Use the font buttons on each direction to swap pairings.

Neo-brutalism · "Bombay Poster"

Mumbai's hand-painted hoardings and shop boards. Every brief is a poster with the brand name as the headline, flat signage colours, thick ink outlines and hard block shadows. Buttons press into the page when you tap them. Taxi yellow (peeli) is only for the one action you came to take. A pitch's status is a rubber stamp on a perforated ticket.

Minimalism · "Quiet Register"

A calm register on warm paper. Briefs are entries in an index, not cards: the brand name set in a serif, details in a quiet sans, separated by hairlines. There are no shadows, boxes or decoration. One vermilion (sindoor) colour marks the action. A pitch's progress is one thin line with four ticks, and the Schbang team's note reads like a quotation.

Where the fonts came from

  • Fontshare: Indian Type Foundry's free library (Tanker, Cabinet Grotesk, Panchang, Supreme, Switzer, Zodiak, Gambetta, General Sans). See also this review of Fontshare's licence.
  • Google Fonts (open licence): Martian Mono (Evil Martians), Anek Latin and Anek Devanagari, Mukta (Ek Type), Teko, Hind and Sarpanch (Indian Type Foundry), Tiro Devanagari Hindi (Tiro Typeworks).
  • Lists we checked and passed over because their picks are now everywhere (Space Grotesk, Archivo Black, Syne, Bricolage, Inter, Space Mono): neobrutalism.com, Kristi Digital, Typewolf, Font Alternatives on neo-grotesk fatigue.

Picking one

Say which direction and pairing, e.g. "Neo-brutalism, Poster" or "Minimalism, Register". It gets built on its own branch, like the clay one, and nothing goes to main.
