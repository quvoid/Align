Align: Minimalism, redone from real references

The first minimal pass used a serif, thin lines and italic quotes, which is the "AI editorial" look. This version follows how real creator-marketplace and job-board apps on Dribbble are built:

  • one clean sans-serif (General Sans, Indian Type Foundry);
  • soft grey screens with white rounded cards;
  • a brand avatar and icon facts on every brief;
  • pill filters, a segmented control and a bottom tab bar;
  • one blue, only for the main action.

References: Pairy influencer app (light cards, chip filters, tab bar), Influencer Platform App (summary strip, campaign card fact row, sticky apply bar), Influencer Marketplace App (dashboard tiles, recent list), Jobhuntly (company avatar + listing details, admin sidebar). Everything is clickable: filters, likes, the dashboard tabs, pitch formats, and the admin queue (keys S, A, N).
